\begin{twocolentry}{}
\href{https://github.com/faketut/VoxFlow}{\textbf{VoxFlow}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Bidirectional Twilio $\leftrightarrow$ Ultravox media over WebSocket, driven by a multi-stage call FSM (greet $\rightarrow$ verify $\rightarrow$ schedule) with per-stage voice switching.
\item n8n post-call automation: TZ-aware calendar booking, HMAC-SHA256 signed outbound webhooks, retry with exponential backoff.
\item Hardened ops---Twilio signature validation, WS idle timeout, structured JSON logs, non-root Docker image with \texttt{/health}---all covered by a pytest suite.
\end{highlights}
\end{onecolentry}
