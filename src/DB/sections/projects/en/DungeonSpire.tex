\href{https://github.com/faketut/DungeonSpire}{\textbf{DungeonSpire}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Decoupled simulation from \texttt{AnsiRenderer} via interfaces + polymorphic entities, so \texttt{doctest} drives combat/AI headlessly without a live TTY.
\item Seeded PRNG (\texttt{-{}-seed}) yields byte-stable procedural runs, making regressions in map connectivity and spawn rules catchable in CI.
\item 7-job CI matrix per push: \texttt{g++}/\texttt{clang++} builds, CMake, ASan+UBSan, \texttt{clang-tidy}, \texttt{cppcheck}, coverage upload.
\end{highlights}
\end{onecolentry}
