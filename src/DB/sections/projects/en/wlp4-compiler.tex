\href{https://github.com/faketut/C-class-compiler}{\textbf{wlp4-compiler}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Multi-pass C++ pipeline: \texttt{wlp4scan} $\rightarrow$ \texttt{wlp4parse} (LR) $\rightarrow$ \texttt{wlp4type} $\rightarrow$ \texttt{wlp4gen} emitting ARM64 assembly.
\item Codegen lowers control flow, procedures, and pointer/array ops with a stable calling convention; full transitions traceable through annotated \texttt{.wlp4ti} trees.
\item \textbf{$-$79.6\%\ output size vs the reference \texttt{wlp4c}} across 65 programs; CI gates every push on the 25-program byte-equal regression suite.
\end{highlights}
\end{onecolentry}
