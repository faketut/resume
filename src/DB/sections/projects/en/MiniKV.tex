\href{https://github.com/faketut/MiniKV}{\textbf{MiniKV}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Go LSM engine---CRC32C WAL, skip-list MemTable, snappy block SSTables with sparse index + file-level Bloom so negative lookups skip disk.
\item Serializable optimistic transactions: snapshot reads, buffered writes, commit-time read-set validation against a bounded commit log---atomic on no conflict.
\item Async leader/follower replication over HTTP NDJSON and gRPC streaming; followers resume from local \texttt{LastSeq()} on reconnect so applied events aren't replayed.
\end{highlights}
\end{onecolentry}
