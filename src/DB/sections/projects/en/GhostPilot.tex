\textbf{GhostPilot}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Invisible Windows overlay streams WASAPI loopback audio through partial/final Azure ASR into a text LLM, with a watchdog auto-restarting the capture pipeline.
\item Alt+P vision path: Qt area capture $\rightarrow$ JPEG $\rightarrow$ vision LLM, result folded back into the text-LLM prompt.
\item Local RAG over \texttt{knowledge/} injects user-curated context so answers stay grounded across long sessions.
\end{highlights}
\end{onecolentry}
