\href{https://github.com/faketut/FoodWeOrder}{\textbf{FoodWeOrder}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Idempotent WeChat Pay callbacks with verified signatures; slow I/O offloaded to a worker queue to keep the web tier non-blocking at peak load.
\item Eliminated inventory oversell by wrapping stock checks and order inserts in row-locked DB transactions with atomic decrements.
\item Vendor dashboard (daily sales, SKU velocity, repeat rate) fed straight off the transactional schema---no manual tallies.
\end{highlights}
\end{onecolentry}
