\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Built a Flask ordering service with WeChat Pay integration: verified callbacks, idempotent order settlement, and slow/third-party I/O pushed to a background worker queue to avoid blocking the web tier at peak load.
\item Eliminated inventory oversell under concurrent checkouts by wrapping stock checks and order inserts in short DB transactions with atomic decrements (row-level locking), keeping on-hand counts aligned with fulfilled orders.
\item Delivered a vendor dashboard (aggregated daily sales, SKU velocity, repeat customers) fed from the transactional schema so owners could adjust stock and pricing from live operational metrics rather than manual tallies.
\end{highlights}
\end{onecolentry}
