\begin{highlights}
\item Auto-provisioned per-user Ed25519 keypair on GitHub OAuth; SimpleWebAuthn passkeys layered on as optional step-up evidence, not the signing key.
\item Each signature stores content hash, payload hash, signature, and key fingerprint under Supabase RLS---tamper-evident audit trail per signer.
\item On finalize, canonical \texttt{final\_proof\_hash} is anchored \texttt{bytes32} to Arbitrum Sepolia via Ethers v6; proof API exports a self-contained package for an offline verifier.
\end{highlights}
