\begin{twocolentry}{}
\href{https://github.com/faketut/ArmyOfSafeguards}{\textbf{ArmyOfSafeguards}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Ensemble of four DeBERTa safeguard heads (toxicity, sexual, jailbreak, factuality) run in parallel via \texttt{expert\_runner}, hot-swappable through env vars.
\item Learned logistic meta-aggregator fuses per-expert probabilities into a calibrated verdict, beating threshold/weighted baselines on held-out HF benchmarks.
\item Training pipeline turns HF labels into expert-Q features and meta JSONL, so adding a new expert needs no aggregator changes.
\end{highlights}
\end{onecolentry}
