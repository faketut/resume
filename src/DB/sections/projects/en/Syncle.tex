\begin{twocolentry}{}
\href{https://github.com/faketut/Syncle}{\textbf{Syncle}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Android spatial-collaboration client in Kotlin + Jetpack Compose: 2D office map on pure Canvas with AABB walkability, edge-clamped camera follow, and edge-distance table proximity (not center-only) for tap-to-join.
\item Realtime layer over LiveKit: 20\,Hz binary position packets with remote-peer lerp, distance-based spatial audio gain, and per-table acoustic isolation via \texttt{table\_id} participant attributes.
\item Node/TS backend (Docker Compose with \texttt{livekit-server}) signs JWTs bound to a device-persistent \texttt{userId} so identity survives restarts; CI runs ktlint + unit tests and uploads debug APKs on \texttt{main}.
\end{highlights}
\end{onecolentry}
