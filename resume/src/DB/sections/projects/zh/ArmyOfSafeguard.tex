\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item 构建可插拔的 LLM 安全框架，采用三层防护：规则引擎（关键词/正则硬过滤）、领域二分类专家（如 NSFW、暴力、仇恨、隐私）以及元分类器；元分类器通过加权门控融合专家 logits 与上下文信息（用户等级、频率、历史），在安全与有用性之间取得平衡。
\item 使用 LoRA（rank 16, $\alpha$ 32）对 DeBERTa-v3（86M）进行微调，仅训练 $<$1\% 的参数，在单张 T4 上实现 sub-50ms 推理；基于公开 NSFW 数据与中性语境样本训练，降低医疗/教育文本的误报。
\item 针对 Llama-3-8B 进行 5,000 样本红队基准测试；部署动态阈值与灰度区间（置信度 0.6--0.8）用于人工或更强模型复核，在保留任务上达到 $\sim$80\% F1，同时将端到端业务准确率提升至 95\% 以上。
\end{highlights}
\end{onecolentry}
