\begin{highlights}
\item 使用 C++ 实现端到端 WLP4 编译器：手写扫描器、SLR(1) 表驱动解析器、在语法树上的语义遍历，并生成具备栈帧意识的 ARM64 代码，覆盖课程语言子集的全部特性。
\item 构建带作用域的符号表并在声明、表达式与过程调用间进行类型检查；将控制流、过程，以及指针/数组结构正确降级为 ARM64，保证一致的调用约定与栈布局。
\item 通过回归用例库（讲师风格与自定义程序）验证全流程，结合汇编级检查与端到端运行，在集成前捕捉词法、语义与代码生成缺陷。
\end{highlights}
