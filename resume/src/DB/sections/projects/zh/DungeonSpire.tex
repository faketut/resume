\href{https://github.com/faketut/DungeonSpire}{\textbf{DungeonSpire}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item 实现 C++ 终端 Roguelike，采用 RAII 管理所有权并通过 Valgrind 做到无内存问题；可选子系统（天气、任务）通过 CLI 开关以插件方式接入，使核心循环保持精简且便于重建迭代。
\item 通过接口与多态实体将模拟（战斗、AI、程序生成）与终端渲染解耦，从而在无需真实 TTY 或 GUI harness 的情况下进行无头单元测试。
\item 使用带种子的程序化生成，让地图与遭遇布局可复现，便于在 CI 风格测试中捕捉连通性、刷怪规则与战斗不变量的回归问题。
\end{highlights}
\end{onecolentry}
