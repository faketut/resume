\begin{twocolentry}{\hspace{.5pt} \href{https://www.cooperators.ca/}{Co-operators Designathon}}
\textbf{Smart Handoff: 全渠道线索生成}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item 设计端到端用户流程与 Figma 线框图，将数字化线索收集与沉淀流程串联为“顾问可直接接手”的用户画像。
\item 协作后端逻辑与数据驱动方案，提升线索到顾问的匹配质量与效率。
\item 制定全渠道策略——包含付费广告与达人/影响者投放——优化用户触达与参与度，提升高质量销售线索数量。
\end{highlights}
\end{onecolentry}

\begin{twocolentry}{\hspace{.5pt} \href{https://www.cooperators.ca/}{Co-operators Designathon}}
\textbf{Smart Handoff: 全渠道线索获取}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item 设计端到端用户流程与 Figma 线框图，将数字化获客链路梳理为可交付给顾问的标准化客户画像。
\item 协作完善后端逻辑与数据驱动方案，提升线索与顾问的匹配效果。
\item 制定全渠道策略（付费投放与影响者营销等），优化用户参与度并提升高质量销售线索数量。
\end{highlights}
\end{onecolentry}
