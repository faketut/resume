\href{https://github.com/faketut/DungeonSpire}{\textbf{DungeonSpire}}
\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Implemented a C++ terminal roguelike with RAII ownership and Valgrind-clean runs; optional subsystems (weather, quests) plug in behind a CLI toggle so the core loop stays small and rebuild-friendly.
\item Separated simulation (combat, AI, procedural generation) from terminal rendering via interfaces and polymorphic entities, enabling headless unit tests without a live TTY or GUI harness.
\item Used seeded procedural generation so map and encounter layouts are reproducible, making regressions in connectivity, spawn rules, and combat invariants easy to catch in CI-style test runs.
\end{highlights}
\end{onecolentry}
