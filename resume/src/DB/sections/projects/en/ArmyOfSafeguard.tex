\end{twocolentry}
\begin{onecolentry}
\begin{highlights}
\item Built a 3-layer safety system with rule-based filters, binary classifiers, and a meta-classifier to combine results for real-time checks.
\item Fine-tuned DeBERTa-v3 using LoRA; used neutral-context data to lower false alarms in medical and educational topics.
\item Built an expert runner to handle parallel tasks and an aggregator to merge model scores, improving detection stability.
\end{highlights}
\end{onecolentry}
